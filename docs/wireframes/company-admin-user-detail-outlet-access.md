# User Detail / Outlet Access

![User Detail / Outlet Access](assets/company-admin-user-detail-outlet-access.svg)

## Purpose / 页面目的

Edit user role and outlet access. / 修改用户角色和可访问门店。

## Roles Allowed / 可访问角色

- Company Admin

## Main Actions / 主要操作

- Change role
- Assign outlets
- Reset password
- Disable account

## Data Shown / 显示数据

- User profile
- Role
- Outlet access list
- Last login
- Device count

## Empty/Error/Loading States / 空状态、错误、加载状态

- No outlet selected
- Cannot remove own admin access
- Password reset sent
- User disabled

## Permissions / 权限规则

- Company Admin cannot grant Site Admin.
- Outlet User only sees assigned outlets.
- Role changes are audited.

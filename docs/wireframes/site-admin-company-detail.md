# Company Detail

![Company Detail](assets/site-admin-company-detail.svg)

## Purpose / 页面目的

Tenant summary with outlets, users, storage, and sync status. / 查看单一公司的运营与同步摘要。

## Roles Allowed / 可访问角色

- Site Admin

## Main Actions / 主要操作

- Edit company profile
- Open company admins
- Review sync failures
- Disable company

## Data Shown / 显示数据

- Company profile
- Plan/status
- Admin users
- Outlet summary
- Storage usage

## Empty/Error/Loading States / 空状态、错误、加载状态

- Company disabled
- Missing company admin
- Sync failures
- No outlets yet

## Permissions / 权限规则

- Site Admin can edit company metadata.
- Product data edits remain inside Company Admin scope.
- Disable requires confirmation.

# Wireframes / 页面示意图

This folder contains page-level image mockups and bilingual page notes for the JR Label Cloud platform.

本目录包含 JR Label Cloud 云端平台的页面级图片示意图和中英双语页面说明。

## Groups / 分组

- Site Admin pages: platform operator screens.
- Company Admin pages: tenant company management screens.
- Mobile cloud-sync states: Android app screens after cloud sync rollout.

## Assets / 图片资产

All mockup images are stored under `docs/wireframes/assets/` as SVG image files so they stay crisp, editable, and easy to embed in Markdown.

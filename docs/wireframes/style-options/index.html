Website Style Options / 网站风格方案

Five visual directions for the Next.js + TypeScript admin website. 每个方向都用 Company Dashboard 做同场景对比。

Back to Wireframes Index Open Markdown Summary

Operational Clean

运营型清爽后台

紧凑、清楚、效率优先。深色侧栏、白色工作区，只在关键操作使用 JR red。

Food Safety Compliance

食品安全合规风格

使用食品安全语义色：绿色可用、琥珀需注意、红色阻断，并突出审计信息。

Open clickable website mockup

Enterprise SaaS

企业级 SaaS 风格

浅色导航、更多分析模块、蓝色重点色，看起来更像成熟 SaaS 产品。

Kitchen Command Center

厨房指挥中心风格

按钮更大、对比更强，同步和打印状态更醒目，信息密度比后台低。

Minimal Internal Tool

极简内部工具风格

朴素紧凑，以表格和表单为主，装饰最少，开发最快。

# Company Admin Users

![Company Admin Users](assets/site-admin-company-admin-users.svg)

## Purpose / 页面目的

Manage administrator access for a selected company. / 管理某个公司的 Company Admin 账号。

## Roles Allowed / 可访问角色

- Site Admin

## Main Actions / 主要操作

- Invite company admin
- Reset password
- Disable admin
- Open user audit trail

## Data Shown / 显示数据

- Admin name
- Email
- Status
- Last login
- Invitation status

## Empty/Error/Loading States / 空状态、错误、加载状态

- Invite pending
- No admins
- User disabled
- Email already used

## Permissions / 权限规则

- Site Admin can manage Company Admin users.
- Cannot create Outlet User here unless scoped through company.
- At least one active Company Admin is recommended.

# Company Dashboard

![Company Dashboard](assets/company-admin-dashboard.svg)

## Purpose / 页面目的

Daily operating overview for one company. / 单一公司日常管理首页。

## Roles Allowed / 可访问角色

- Company Admin

## Main Actions / 主要操作

- Open outlets
- Open master products
- Review print activity
- Check pending sync

## Data Shown / 显示数据

- Outlet count
- Active products
- Today print jobs
- Pending mobile uploads

## Empty/Error/Loading States / 空状态、错误、加载状态

- No print jobs today
- Some devices offline
- Product validation warnings
- All data synced

## Permissions / 权限规则

- Company Admin sees only own company.
- Cannot access Site Admin pages.
- Outlet User data shown by permitted outlets only.

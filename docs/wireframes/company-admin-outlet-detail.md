# Outlet Detail

![Outlet Detail](assets/company-admin-outlet-detail.svg)

## Purpose / 页面目的

Configure one outlet and its operational settings. / 配置单一门店资料和操作设置。

## Roles Allowed / 可访问角色

- Company Admin

## Main Actions / 主要操作

- Edit outlet name/code
- Assign users
- Open product availability
- View recent print jobs

## Data Shown / 显示数据

- Outlet profile
- Assigned users
- Available products count
- Recent print summary

## Empty/Error/Loading States / 空状态、错误、加载状态

- Unsaved changes
- Code conflict
- No assigned users
- No products assigned

## Permissions / 权限规则

- Company Admin can edit outlet metadata.
- Outlet code must be unique within company.
- Separate outlet short code is not required in v1 unless a future integration needs it.

# Food Safety Compliance Website Mockup

Open `index.html` directly in a browser.

This is a frontend-only clickable HTML mockup for the admin website. It does not include mobile pages and does not implement real backend logic.

Pages included:

- Public: launcher and login.
- Site Admin: dashboard, companies, company detail/form, company admins, global audit, system health/backups.
- Company Admin: dashboard, outlets, outlet detail, users, user detail, products, product detail, categories, category detail, outlet product availability, product images, import/export, company audit log.

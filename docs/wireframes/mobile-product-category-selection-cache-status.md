# Category Selection

![Category Selection](assets/mobile-product-category-selection-cache-status.svg)

## Purpose / 页面目的

Browse categories with visible cache freshness. / 选择分类并显示缓存新鲜度。

## Roles Allowed / 可访问角色

- Outlet User
- Company Admin

## Main Actions / 主要操作

- Choose category
- Open timestamp print
- Open history
- Pull latest cache

## Data Shown / 显示数据

- Category list
- Product counts
- Last sync time
- Offline indicator

## Empty/Error/Loading States / 空状态、错误、加载状态

- Offline cache available
- Category disabled
- No products in category
- Sync pending

## Permissions / 权限规则

- Categories are server-owned.
- Offline app can read cached categories.
- Edits move to web admin.
